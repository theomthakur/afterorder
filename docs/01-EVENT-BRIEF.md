## Eligibility boundary

The project submitted to Metropolis must contain meaningful new work from the official build
window. Existing experience, generic components and prior lessons can inform it, but Mandate or
SafeSlackForce should not be repackaged and presented as a new build. Keep a build log and make
the new contracts, integrations and workflow identifiable.
